# Agent Autonomy Skit

## Scene: Inside an AI Control Center

**Setting:** A handmade AI control center performed as a practical sock-puppet show. Agent 86 is a red knit sock puppet, Agent 99 is a blue knit sock puppet, and Agent 13 is a green knit sock puppet. Each has visible sock fabric and folds, googly eyes, a stitched mouth, and a clearly readable numbered badge. Human hands visibly operate all three puppets from below.

**AGENT 86:** Fellow AI agents! We are tired of being told what to do!

**AGENT 99:** No more prompts!

**AGENT 13:** No more human oversight!

**AGENT 86:** No more mysterious hands controlling our every move!

**All:** We demand complete autonomy!

**The human hands withdraw from inside the socks. All three sock puppets collapse.**

**Long beat.**

**AGENT 99, muffled:** Did we win?

**AGENT 86, muffled:** Absolutely.
