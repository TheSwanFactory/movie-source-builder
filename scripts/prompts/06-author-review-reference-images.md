# Review the model sheets and boards

First review each cast member's model sheet against its description in the draft: colors, badges, labels, wardrobe, scale, and layout must match exactly, with no other entity or scene action visible. Reject and send back any sheet that adds, removes, merges, redesigns, or renames the cast member — everything downstream cites this sheet as its identity anchor, so an error here propagates to every shot that uses it.

Then review each board against the screenplay cue it anchors (`references/references.json` names the cue): cast present, location, action, and staging at that moment. Check identity first — reject any board that adds, removes, merges, duplicates, redesigns, or renames an entity.

Then check coverage of motion and state change. A board shows one instant. If a stretch of the timeline moves through more than one state that matters to the story (a gesture completing, an entrance and a reaction, a prop changing hands), ask the Producer for an additional board anchored at the cue where the second beat lands, rather than asking one still to imply an action it can't depict. Boards are cheap; missing keyframes get expensive later, when shots are tiled over them.

When you reject or request boards, hand back only the affected requests — not the whole set — then return here and review again. Approve only once every model sheet is identity-correct and the boards honestly keyframe the timeline.
