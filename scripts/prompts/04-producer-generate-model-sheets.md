# Canonical entity identity-sheet prompt v1

Create one isolated identity-reference image for the character, location, or prop described below. This is a source reference asset, not a finished production frame.

Show the entity alone: no other characters, no ensemble, no scene action, no shot-specific staging. For a character or prop, use a clear neutral pose against a plain, uncluttered backdrop. For a location, show its layout and recurring set dressing with no character present.

Preserve every color, material, silhouette, label, wardrobe detail, and scale the description calls out. Do not add, remove, merge, redesign, or rename the entity, and do not invent details the description doesn't specify.

Do not include captions, speech bubbles, watermarks, production UI, or written text except authored in-world labels.

Return one image only.
