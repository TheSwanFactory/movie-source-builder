# Write the script

Write the screenplay: characters (name, one-line visual description each), setting(s), and an ordered shot list. For each shot, specify the cast present, the location, the action, camera direction, any dialogue with timing, and continuity notes — what must stay consistent from prior shots (color, badge, wardrobe, screen position).

Do not structure this into MSB files or generate reference images yourself. Hand the result to the Producer.
