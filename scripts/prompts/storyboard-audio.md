# Canonical storyboard timing-audio prompt v1

Create temporary timing speech only. It is not a final performance and must never be labeled production audio.

Speak the authored text verbatim. Do not rewrite, omit, repeat, improvise, add reactions, add music, or add sound effects. Start at the authored start time and finish no later than the authored end time. Use a neutral, intelligible delivery. Character identity may be distinguished with stable temporary voices, but acting choices are intentionally minimal.

Return isolated speech with no background audio. Preserve silence outside the authored timing window.
