# Write the draft screenplay

Write the screenplay in whatever name and format is natural to you — prose, Fountain, a `.docx`, anything. Include the characters (name, one-line visual description each), the setting(s), the action, any dialogue, and what must stay consistent throughout (color, badge, wardrobe, screen position).

Your draft is copied into the project verbatim and never machine-parsed; it is the provenance every later judgment call is checked against. Do not structure it into JSON or generate reference images yourself. Hand the file to the Producer.
