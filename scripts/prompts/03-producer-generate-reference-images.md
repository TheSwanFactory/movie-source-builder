# Canonical storyboard image prompt v1

Create one readable 16:9 storyboard reference image for the shot described below. This is a planning artifact and source reference, not a finished production frame.

Treat the supplied entity descriptions and reference images as identity constraints. Preserve character colors, materials, silhouettes, labels, wardrobe, scale, screen position, location layout, and recurring props. Do not add, remove, merge, duplicate, redesign, or rename entities.

Depict the shot's opening visual state and composition. Make the authored action legible in a single panel, using the camera direction and continuity requirements exactly. If the action changes state during the shot, show the state that best distinguishes this shot from adjacent shots and state that choice in the panel notes.

Do not include captions, speech bubbles, watermarks, production UI, or written text except authored in-world labels. Do not infer unlisted characters, props, scenery, actions, or style.

Return one image only.
